# 소위에서 별까지 — v2.0

입학부터 전역까지, 한 번에 1년씩 보내는 장교 커리어 게임. TypeScript 엔진(순수 함수) + 바닐라 TS 화면, esbuild로 `dist/index.html` 한 파일.

## 빌드·검증
- 빌드: `ESBUILD=$(which esbuild) node web/build.mjs`
- 타입 검사: `tsc --noEmit -p .`
- 밸런스: `npx tsx sim/balance.ts 300` (봇 4종 원칙·도전·편법·기대값 × 잠재력 4종)

## 구조
- `src/data/config.ts` 밸런스 숫자 전부 (성장 C안, 진급, 보직표 31개, 인사 정원, 지휘 방침, 동기 성격)
- `src/data/choices.ts` 결재 이벤트 34종 + 연쇄 4종 + 중대 사건 4종 (보안 기준 주석 포함)
- `src/data/events.ts` 우연한 일(표창·체력검정 등)과 보직별 업무 성과 문구
- `src/engine/school.ts` 학교 프롤로그 (무작위 출신, 집중 분야, 졸업 석차·병과 배정)
- `src/engine/choice.ts` 결재 확률 = 기본 + (능력치 − 계급 기준) + 태그 8(최대 2) + 교육 5 + 보직 경험 5, 10~95%
- `src/engine/personnel.ts` 희망 조사 1·2지망 → 점수 순 정원 배정 (장성은 가상 선후배 6명과 경쟁)
- `src/engine/promotion.ts` 경력 = 55 + 핵심 25 + 보조 10×n(최대 2) + 출신. 중령 이상 심사는 다른 기수를 채워 10명 풀
- `src/engine/game.ts` 진행: 결재 2건 → 1년 → 진급 → 인사 → 지휘 방침
- `src/engine/meta.ts` 약장 25종(게임 전용 이름, 한 판에 보통 10~17개)·칭호 10종
- `src/ui/insignia.ts` 금속 계급장 (9잎 무궁화·다이아·별 + 화환)
- `src/ui/ribbon.ts` 약장 그림, `src/ui/main.ts` 화면

"광고 자리" 시트로 흉내만 낸다. 교관 평가서(잠재력 공개), 다른 학교로 다시 지원(캐릭터당 1회). 확률·능력치를 파는 광고는 없다.

## 화면 (v2.1 ~ v2.4)
- 회색 바탕(#F2F3F0) + 흰 둥근 카드, 포인트는 국방색(#4B5D3A) 하나. 칩은 회색, 감소 수치만 빨간 글자
- 글씨체: Pretendard가 있으면 쓰고, 없으면 Inter(영문·숫자) + Noto Sans KR(한글). 자간 −0.02em
- 1년 진행: 게이지가 차오르고, 하반기 결재가 있으면 7월에서 멈춤
- 결재 카드: 성공하면 / 실패하면 결과와 확률 근거를 함께 표시
- 이벤트 34종 + 연쇄 4종 + 중대 사건 4종. 안 본 이벤트 우선, 다시 나오면 다른 상황 문구
- 전역 카드: 계급장·약장 → 한 줄 문구 → "중령으로 명예롭게 전역해요" → 동기 기준 상위 % → 평정 수·무사고 지휘·표창 → 칭호·약장 → 공유 버튼

## 서버 (v2.6, Supabase)
- `src/net/api.ts`: 라이브러리 없이 REST로 직접 호출. 공개용 키(publishable)만 들어 있음. service_role 키는 절대 넣지 않기
- 로그인: 익명 로그인 (Supabase 설정에서 Anonymous sign-ins 켜야 함)
- 테이블: `profiles`(닉네임·칭호), `runs`(전역 기록). 권한(RLS): 누구나 읽기, 쓰기는 본인 것만
- `runs.choices`에 `{ log: 선택 기록, card: 전역 카드 숫자 }`를 함께 저장. 선택 기록은 나중에 서버 검증(다시 계산)용
- 첫 화면은 로비(게임 소개·내 최고 기록·오늘의 랭킹). "새로운 군 생활 시작하기" → 이름 → 학교 프롤로그. 진행 중인 판이 있으면 "이어서 하기"
- 주소: `#/card/<판번호>` 공유 카드, `#/rank` 랭킹(오늘의 사령부·랭킹 100·나의 기록), `#/gallery` 커리어 갤러리
- 전역 카드 "이미지로 저장": 캔버스로 1080×1350 PNG를 그려 폰에선 공유 창, PC에선 다운로드 (`src/ui/cardImage.ts`)
- 아직 `verified` 검증 없이 모든 기록을 랭킹에 표시함. 사용자가 늘면 서버 검증 함수 추가 필요
