## v3.4 이어지는 이야기 (구체화)

지금 결재는 한 번 누르면 끝이에요. v3.4는 오늘의 선택이 몇 년 뒤 다시 돌아오게 만들어요. 목표는 "아, 그때 그거!"라는 순간을 한 판에 2~4번 만드는 것.

### 1. 사건 체인
- 체인 시작 결재에서 고른 선택이 씨앗으로 저장되고, 1~4년 뒤 맞는 후속 사건이 결재함에 우선 들어와요.
- 후속 카드 위에 "2029년 '부하의 실수'에서 감싸 주기를 골랐어요" 한 줄.
- 분량: 시작 20개, 후속 30개. 보상은 작게(평정 ±3, 능력치 +2 안쪽).

| 시작 결재 | 선택 | 1~4년 뒤 |
| --- | --- | --- |
| 부하의 실수 | 감싸 주기 | 그 부하가 우수 간부가 되어 추천서 (희망 조사 가점) |
| | 원칙대로 보고 | 감사에서 모범 평가(평정+) / 부하와 서먹해짐 |
| | 조용히 정리 | 나중에 드러나 해명 요구 (마음에 걸리는 일 +1) |
| 신규 제도 시범 운영 | 자원 | 성공 시 전 부대 확대·교관 초빙 / 실패 시 담당자로 남음 |
| 동기의 부탁 | 도와줌 | 몇 년 뒤 인사에서 도움 / 엮여서 같이 문제 |
| 상관의 무리한 지시 | 정중히 거절 | 그 상관이 진급 심사위원으로 재등장 |

### 2. 기억되는 사람
- 한 판에 5~8명(첫 부하, 첫 상관, 라이벌 동기, 은사 등). 관계 -2~+2.
- 후속 사건에 이름으로 재등장. +2면 희망 조사 추천 가점, -2면 발목 잡는 사건.
- 복무 화면 "내 사람들", 전역 화면 "30년을 함께한 사람들".

### 3. 평판
- 결재 성향 누적 → 원칙주의자 · 해결사 · 승부사 · 요령꾼.
- 평판 전용 사건, 상관 궁합(꼼꼼한 상관+원칙주의자 평정+2 등), 전역 카드에 표시.

### 4. 기수 판 연결
- 우리 기수 갈림길·오늘의 기수 "남들과 달랐던 선택"에 체인 결과 표시.

### 일정·검증
- 1~2주(대부분 문구). 체인 판/비체인 판 장군 비율 차 +3%p 안. 한 판당 체인 2~4개.
