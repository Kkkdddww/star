2026-11-13 · 지금까지 나눈 이야기를 한 장으로 정리

## 0. 현재 상태 (11/13 기준)

| 버전 | 들어간 것 |
| --- | --- |
| v3.0 | 오늘의 기수, 인사 개편(부대 카드 5종 · 상관 4종 · 발표 봉투 · 임기 목표), 명예 점수 |
| v3.1 | 우리 기수(코드·링크, 7일, 30명, 순위 · 기수 시상 · 갈림길), 개발자한테 한마디, 로비 정리, 명예의 전당(세 모드 모두 계급 → 명예 점수 → 복무 기간) |
| v3.1.1 | 카드 이미지 바로 공유(이미지 + 한 줄), 한마디 상단 띠, 새 og 이미지 |

**데이터 (도입 첫날)**
- 오늘의 기수 도입 후 1,759명 중 79%가 오늘의 기수를 함
- 오늘의 기수 + 자유 플레이 836명은 자유 플레이 평균 3.9판(자유만 한 사람 2.7판)
- 오늘의 기수만 하고 나간 사람 556명(40%) → 가장 큰 기회
- 우리 기수 26개, 끝난 기수 한 곳당 평균 2.3명

**엔진 진단: 지금은 잠재력 게임**
- 성장 속도와 능력치 상한이 잠재력으로 정해지고, 평정·결재 확률·인사·진급이 모두 능력치를 거침
- 시뮬(150판): S + 최악의 선택 대령+ 55% vs B + 최선의 선택 대령+ 4.7%
- B·C(후보의 65%)는 사실상 장군 불가 (상한 76 · 70)
- 그래서 오늘의 기수 순위권이 잠재력 높은 후보를 고른 사람으로 채워짐

## v3.2 공정한 출발선 (다음 패치)

**A. 기수 판 잠재력 고정 (바로)**
- 오늘의 기수 · 우리 기수는 후보 3명 잠재력을 모두 같게. 기본 **A 고정** (C로 하면 별이 사라짐)
- 기수 판에서는 교관 평가서 제외
- 선택: 요일별 난이도 (평일 A · 토 S · 일 B), 로비에 "오늘은 A 기수"
- 이미 끝난 오늘 기록은 그대로, 다음 날 0시부터 적용

**B. 잠재력 영향 줄이기 (본 작업)**

| 잠재력 | 성장(지금 → B안) | 상한(지금 → B안) |
| --- | --- | --- |
| S | 12~14 → 11~13 | 92 → 90 |
| A | 9~11 → 9~11 | 84 → 87 |
| B | 6~8 → 8~10 | 76 → 84 |
| C | 4~6 → 7~9 | 70 → 81 |

- 각성 확률: C 30→45%, B 15→30%, A 6→15%
- 시뮬 결과(대령+): B + 최선 4.7% → **29.2%**, C + 최선 0% → 11.7%, S + 최악 34%. 잠재력과 실력이 같은 무게
- 다른 기수 평균(VIRTUAL_MEAN) 재조정으로 장군 목표(준장+ 8% · 중장+ 1% · 대장 0.4%) 유지
- 명예의 전당은 "시즌 1" 보관 후 새로 시작

**같이 하는 작은 것**
- 오늘의 기수 전역 화면에 다음 행동 두 개: "자유 플레이로 한 판 더", "친구랑 우리 기수 만들기"
- 개발자 이름 확정(후보: 인사과장) + 사칭 방지(개발자·운영자·관리자·GM·본인 이름 차단, 배지는 계정 기준)
- 한마디 개발자 답글 알림 점

작업량: A는 30분, B까지 약 1~2일

## v3.3 기수 대항전

**규칙**
- 매주 월 0시 ~ 일 24시. 기수를 만들 때 "대항전 참가"(기본 켜짐)
- 참가 기수는 모두 그 주의 같은 세상(주간 시드) + 잠재력 동일
- 한 사람은 한 주에 대항전 기수 한 곳에만 기록
- 순위 조건: 전역자 **3명 이상** (실데이터 2.3명을 반영해 5명에서 낮춤)

**팀 점수**
- 개인 = 계급 점수(계급마다 100) + 명예 점수
- 팀 = 상위 3명 평균 + 인원 보너스(4번째부터 1명당 +5, 최대 +50)
- 못하는 친구를 불러도 깎이지 않음 → 초대할수록 이득

**기수 마크** (계급장 대신 팀 표시)
- 모양 4(방패·원형·육각·깃발) × 상징 10(별·산·번개·불꽃·화살·날개·나침반·달·소나무·파도) × 색 8
- 숫자·글자·동물·무기 없음 → 실제 부대 마크와 겹치지 않음

**들어오는 길**
- 초대 링크 · 코드 · QR
- 공개 기수 모집 목록 + "아무 기수나 들어가기" 자동 배정 (혼자 하는 556명을 팀으로)

**포상 (꾸미기만, 말뚝 문서 디자인으로)**
- 우승: **표창장**(제 2026-47호 · 말뚝 인사과장 도장) → 공유 이미지로도 사용
- 약장 "기수 대항전 우승", 마크 금테(영구, 우승마다 별 추가)
- 랭킹 닉네임 옆 **표창 도장** 7일 (표창 ×2처럼 횟수 표시)
- 역대 우승 기수 목록

**화면**
- 로비 광장: 대항전 1~3위 + 우리 순위 + 마감
- 대항전: "포상 계획" 공문 → 중간 집계(▲▼ 변동) → "3위까지 48점"
- 기수 페이지: 순위 · 팀 점수 · 다음 순위까지, 점수에 반영된 3명 표시
- 전역 화면: "팀 점수에 들어갔어요 · 9위 → 5위"
- 오늘의 기수도 "전역 현황" 형식으로: 1~3위, 내 위·내 줄, "47위까지 명예 3점", 최근 전역

**위험 대응**
- 대항전 기수 이름은 숫자 없는 부대 단어도 차단, 신고 3회면 "이름 숨김 기수"
- 인원 부풀리기 이득은 최대 +50으로 제한

작업량: 3~4일 + 마크 반나절 + 공개 모집·자동 배정·QR 1일

## v4.0 클랜전

- **클랜(가칭 전우회):** 계속 유지되는 팀. 이름 · 마크 · 회장 1 · 간부 2 · 30명. 초대 · 공개 모집 · 가입 신청과 승인. 클랜 레벨과 꾸미기 해금
- **1:1 클랜전:** 매주 비슷한 점수끼리 짝. 같은 주간 세상. 멤버는 하루 한 판, 그날 상위 3명이 그날 점수, 7일 합계로 승패. "우리 1,840 vs 상대 1,792 · 3일 남음"
- **시즌:** 4주. 등급 예비 → 정규 → 정예 → 최정예 → 전설. 시즌 약장 · 마크 테두리
- **소통:** 자유 채팅 없음(비용 · 실제 부대 이야기 위험). 정해진 응원 문구 + 공지 한 줄
- **관리:** 회장 2주 미접속 시 간부에게 자동 이양, 빈 클랜 정리, 이름 · 공지 필터, 신고 숨김
- 서버: 주간 짝짓기 예약 작업 1개, 점수는 집계 +1 방식 → 무료 플랜 안

작업량: 1~2주. 대항전의 마크 · 공개 모집 · 자동 배정을 그대로 이어받음

| 꾸미기 상점 | 카드 테마, 표창장 디자인, 마크 상징 · 색, 프로필 장식 | 1,000~3,000원 |

| 대항전 후원(제휴) | "이번 주 후원" 한 줄 + 우승 상품 | 협의 |

- 대략 규모(가정): 월 활성 2만 명 × 결제 1.5% × 4,900원 → 시즌 기록부 시즌당 약 150만 원
- **복무 중 영리활동 금지(군인복무기본법 제30조, 병사 포함)** → 결제는 만들어 두고 2027-03-21 전역 후에 켜기
- 국내 결제(PG)는 보통 사업자등록 필요 → 전역 후 사업자등록 → 결제 연결

**순서:** 지금~전역 광고 승인만 · 데이터 키우기 → 전역 직후 광고 · 광고 제거 → 첫 시즌 시즌 기록부 → v4.0 클랜 후원 · 상점

2. 잠재력 B안 적용 + 명예의 전당 시즌 구분 여부
