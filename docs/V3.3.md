# v3.3 명세 · 로그인 + 인사기록카드 + 기수 대항전

2026-11-14 확정 대기 · 시안은 대화에서 공유 (로비 탭, 대항전, 기수 페이지, 기수 약장, 인사기록카드)

## 한 줄 목표
기기를 바꿔도 내 경력이 이어지고, "우리 기수"가 소속이 되어 매주 돌아오게 한다.

## 1. 로그인
| 항목 | 내용 |
| --- | --- |
| 방식 | 지금 익명 계정에 구글 · 카카오 **연결**. 지금 기록 그대로 |
| 로그인 없이 | 다 할 수 있음. 단 **기수 만들기만 로그인 필요** |
| 서버 저장 | 약장 도감 · 칭호 · 최고 기록 · 호봉 · 기수. 진행 중인 판은 기기에만 |
| 받는 정보 | 로그인 고유번호만 사용. 이메일 · 이름 표시 안 함. 개인정보처리방침 수정 |
| 기기 충돌 | 로그인 계정 기록을 쓰고, 다른 기기의 익명 기록은 그대로 둠 (안내) |
| 사용자 설정 | 구글 클라우드 OAuth · 카카오 디벨로퍼스 앱 · Supabase 인증(계정 연결 켜기) · 돌아올 주소 malttuk.com. 비밀 키는 Supabase에만 |

## 2. 닉네임
- 계정마다 하나로 고정. 처음 한 번 정하고, 업로드 때는 버튼만
- 변경은 인사기록카드에서 **7일에 한 번**. 바꾸면 예전 기록도 새 이름으로 표시
- 새로 정하거나 바꾸는 닉네임은 **겹치면 안 됨**(대소문자 · 띄어쓰기 무시). 이미 겹치는 기존 이름은 그대로 두고 바꾸기를 한 번 권함
- 실데이터: 프로필 6,908개 중 겹치는 이름 580개(2,319명, 최대 235명)

## 3. 인사기록카드 (개인 프로필)
- 랭킹 · 기수 명부 · 대항전 순위 어디서든 사람을 누르면 아래에서 올라옴. 로비 맨 위 한 줄을 누르면 내 카드
- 내용: 최고 계급장 · 닉네임 · 칭호 · 군번(26-01247) · 호봉과 다음 호봉까지 · 판 수 / 장군 전역 / 대장 · 소속 기수(대표 표시) · 자유 최고 · 명예의 전당 순위 · 오늘의 기수 최고 순위와 참가 일수(연속) · 대항전 기록 · 약장 랙 · 최근 전역(카드 열기)
- 전부 공개 (닉네임 기반 게임 기록만)

## 4. 호봉
| 활동 | 경험치 |
| --- | --- |
| 판 끝내기 | 10 + 도달 계급(소위 10 ~ 대장 55) |
| 오늘의 기수 | +30 (하루 1번) |
| 대항전 판 | +20, 기수 1~3위면 주간 +50 |
| 자유 플레이 | 하루 5판까지만 |
- 1호봉부터, 갈수록 조금씩 더 필요. 30호봉까지 약 두 달, 상한 없음
- 5호봉마다 꾸미기 해금(기수 약장 새 색 · 줄무늬, 전역 카드 테마, 칭호, 카드 장식)
- 경험치는 서버 함수가 계산 (앱에서 임의로 못 올림)
- **능력치 · 확률 · 잠재력 보상 없음**

## 5. 기수 대항전
| 항목 | 내용 |
| --- | --- |
| 기수 | 계속 가는 팀. 이름 · 구호 · **기수 약장** · **기수 번호(제128기, 만든 순서)**. 최대 30명. 만든 사람이 기수장(이름 · 구호 · 약장 수정) |
| 소속 | 여러 기수 가능, **최대 3곳**. 랭킹에는 본인이 고른 대표 기수 하나 |
| 회차 | 매주 월 0시 ~ 일 24시. **첫 회차 11/30(월)** |
| 판 | 한 사람 한 주 **한 판**, 그 판이 속한 모든 기수 점수에 들어감 |
| 출발선 | 그 주 대항전은 모두 같은 주간 세상(월요일 날짜로 생성) + 잠재력 A(난이도 보통). 판정 주사위만 rollSeed |
| 팀 점수 | 상위 3명 평균(2명이면 2명) + 4번째부터 1명당 +5(최대 +50). 순위는 전역자 2명 이상 |
| 혼자인 사람 | 공개 기수 목록 + 아무 기수나 들어가기(인원 적은 공개 기수) |
| 쉬는 기수 | 2주 동안 아무도 안 하면 순위표 · 공개 목록에서만 빠짐 |
| 기존 우리 기수 | 7일짜리 친선 기수로 남김 |

**기수 약장**: 바탕색 8 × 줄무늬 모양 6 × 줄무늬 색 5 = 240가지, 무작위 뽑기, 같은 조합 허용(알려만 줌). 성적이 약장 위에 붙음: 4주 참가 동별 → 입상 은별 → 우승 금별 + 금테.

**포상 (꾸미기만)**: 1~3위 기수 표창장(제2026-NN호 · 말뚝 인사과장 도장, 이미지 저장 · 공유), 기수 연혁에 영구 기록, 약장 위 별 · 금테.

**소속감 장치**: 기수 번호 · 동기 번호 · 창설 동기 표시, 구호, 명부, 연혁, 주간 기수 시상, 점수에 들어간 3명 + "인원 +5를 보탠 동기", 아직 안 한 동기 부르기, (2차) 게임 속 동기 이름 = 기수원, 우리 기수 선택 비율, 출사표 한 줄.

| 설정 | 계정 연결 · 로그아웃 · 계정 삭제 |

## 7. 서버 (SQL Editor에서 먼저 Run)
- `profiles`: 호봉 · 경험치 · 군번 · 대표 기수 · 꾸미기 · 닉네임 변경일. 새 닉네임 겹침 금지(기존 허용)
- 경험치 서버 함수(판 업로드 때 계산)
- `cohorts`: 대항전 여부 · 기수 번호 · 약장(바탕 · 모양 · 색) · 구호 · 공개 · 기수장
- `members`: 기수 · 사람 · 동기 번호 · 들어온 날 · 대표 여부. 한 사람 최대 3곳
- `runs.week` + 한 사람 한 주 한 판
- `contest_board` 뷰: 주별 팀 점수 · 순위
- (2차) `notes`: 출사표

## 8. 같은 출발선 · 밸런스
- 대항전 세상은 주(월요일 날짜)에서 생성. 서버 시드를 믿지 않음
- 호봉 · 꾸미기 · 동기 이름 바꾸기는 판정에 영향 없음. 엔진 수치 변경 없음

## 9. 위험
- 기수 이름 · 구호 · 출사표: 실제 부대처럼 보이는 단어 차단, 신고 3번이면 숨김
- 한 사람이 여러 기수 점수 올리기: 최대 3곳으로 제한
- 개인정보: 이메일 비표시, 처리방침 수정, 계정 삭제 제공
