# 말뚝 디자인 규칙

말뚝의 화면은 **군 행정 문서**다. 사용자는 화려한 장식을 "AI스럽다"며 싫어했고, 상자 안 상자 같은 큰 개편도 되돌렸다. 새것보다 일관성이 우선.

## 써야 하는 것
- 회색 배경(var(--bg)) 위 흰 종이 카드, 모서리 둥글게, 1px 줄(var(--line))
- 색은 국방색 하나(var(--olive), 연한 바탕 var(--olive-t)). 실패·경고만 빨강(var(--red))
- 문서 형식: 문서번호(`.no`), 제목 자간 띄우기(인 사 명 령, 표 창 장), 도장(`.stamp`, 빨강 또는 국방색 원), kv 표(`.kv`)
- 기존 클래스 재사용: `.doc .hd .bd`, `.kv`, `.chip`(on·gray·red·amber·line), `.paper`, `.stamp`, `.opt`, `.row`, `.newnote`, `.sec`, `.kicker`, `.h1 .h2 .sub .faint`, `.bar .btn .btn.line .two`
- 아이콘은 `src/ui/main.ts`의 `icon()` 선 아이콘만. 계급장은 `insignia()`
- 문구: 짧은 해요체. 숫자는 구체적으로("47위까지 명예 3점"). 강조는 굵게 한 곳만

## 쓰지 않는 것
- 어두운 배경·그라데이션 히어로, 금색·네온, 빨간 LIVE 점, 이모지, 시상대, 큰 카운트다운 시계
- 상자 안에 상자를 겹치는 구성
- 새 색·새 글꼴·새 그림자 체계
- 실제 부대 마크·실제 훈장 모양을 닮은 그림 (기수 마크는 단순 도형·상징만)

## 경쟁·보상 화면을 만들 때
- 실시간 느낌은 "방금 / 1분 전" 표로, 순위는 "내 위 한 줄 + 내 줄 + 다음까지 몇 점"으로
- 보상은 표창장·포상 계획 같은 **문서**로 보여준다(예: 제 2026-47호 표창장, 말뚝 인사과장 도장)
- 우승 표시는 작은 도장 "표창" 또는 테두리 글씨 하나

## 확인
- 390px 폭 스크린샷으로 확인(malttuk-qa). 글자 넘침, 두 줄로 깨지는 칩, 바에 가려지는 버튼을 고친다.
- 큰 화면 변경은 먼저 시안 스크린샷을 보여주고 확인받는다.
