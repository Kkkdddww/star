# 말뚝 글쓰기 규칙

## 소재 (가장 중요)
- 쓰는 것: 사람 사이 일, 행정·인사·교육·행사·보고 일정·관행·가족·동기·상관·부하와의 관계
- 쓰지 않는 것: 실제 부대 이름·번호·위치, 무기 이름·제원, 작전·경계·대응 절차, 보고 체계, 교전 기준, 암구호, 실제 인물, 실제 사건을 떠올리게 하는 사고·가혹행위·사망
- 결과는 행정적인 것만: 평정, 표창, 인사(보직·추천), 관계, 평판, 약장, "마음에 걸리는 일"
- 인물 이름은 흔한 성 + 무작위 이름. 실존 인물과 겹치는 조합은 피한다

## 톤
- 짧은 해요체 서술, 장면이 그려지게 한두 문장. 대사는 따옴표로 한 줄
- 선택지 이름은 동사로 끝나는 짧은 구("같이 밤을 새운다", "정중히 거절한다")
- 정답처럼 보이는 선택지를 만들지 않는다. 각 선택에 얻는 것과 잃는 것이 있어야 한다
- 군대 은어는 누구나 아는 수준만

## 효과 크기 (밸런스)
- 일반 결재: 평정 ±2~6, 능력치 ±1~3. 확률이 낮을수록 보상 배율이 붙는다(choice.ts의 rewardTier)
- 이어지는 이야기(v3.4): 1·2장은 주사위 없음, 관계 ±1·처세/평판 위주, 평정 ±2 이하. 3장(결말)만 주사위, 보상은 표창·약장·진급 심사 +2 이하
- 희귀 사건: 기억에 남는 연출이 목적, 수치는 일반 결재 수준

## 데이터에 넣기
- 결재 사건은 `game/src/data/choices.ts` 형식을 따른다(id, type, options[{key,label,style,desc,success,fail}])
- 새 글을 넣었으면 같은 출발선 모드에서 모두에게 같은 사건이 나오는지(세상 시드 사용) 확인
- 초안은 Claude가 쓰고, 사용자에게 "군 생활 감각으로 손볼 곳"을 물어 반영한다
